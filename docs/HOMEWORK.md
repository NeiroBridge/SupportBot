# Отчёт по домашнему заданию

В уроке разобрал схему `SupportTicket`: обязательны имя, контакт, проблема, время, место и приоритет. `SupportSession` хранит user/chat id, ticket, историю диалога и флаги `started` / `submitted`. Нейросеть отвечает JSON `AssistantTurn`: `reply`, `extracted_ticket`, `ready_to_submit`.

Для демо студии NeiroBridge универсальная «поломка техники» не подходит, поэтому сделал новый сценарий с двумя режимами: заявка на бесплатную диагностику и поддержка по проекту.

Общими полями оставил имя и контакт. Для лида добавил компанию, тип запроса, цель, текущие инструменты и срок. Для поддержки — проект, суть проблемы, когда началось, контур (сайт / бот / n8n / CRM / сервер) и приоритет.

Промпт переписал под NeiroBridge: услуги, диагностика 0 ₽ за 1–2 дня, контакты neirobridge.ru и @neirobridge_ai, запрет выдумывать почту, телефон и цены. Валидация не принимает мусор в имени и приводит тип запроса, место и приоритет к фиксированным значениям.

Workflow: /start → выбор режима кнопкой → один вопрос за раз → JSON от модели через ProxyAPI → если поля режима полные, карточка в канал оператора. Сессии пишутся в SQLite, чтобы диалог не сбрасывался после перезапуска.

Проект задеплоил на свой сервер через Docker и вывел в прод: бот @neirobridge_support_bot круглосуточно принимает заявки и служит живым демо для заказчиков. Пайплайн урока сохранён, но решение уже работает как продукт студии.
